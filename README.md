# AI4TM - AI for Marketing Masterclass

Content, notebooks, and guides for the AI for Marketing (AI4TM) masterclass — 6 sessions covering AI fundamentals, evaluation, compliance, synthetic data, knowledge graphs, and agentic workflows.

## 🚀 Getting Started (100% Free)

This course uses **Google's free tier** — no credit card required.

### Quick Start (10 minutes)

1. **Get a free Gemini API key**:
   Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey) and create a free key

2. **Open notebooks in Google Colab**:
   Click any `.ipynb` file in this repository → Look for "Open in Colab" badge → Click it

3. **Start with the setup guide**:
   [session_1/setup_guide.ipynb](session_1/setup_guide.ipynb)

**That's it!** No installation, no credit card, no complex setup.

### What You Get for Free

✅ Google Colab - Run code in your browser
✅ Gemini API - 250 free requests/day (resets daily, never expires)
✅ GitHub - Save and share your work
✅ Free GPUs in Colab (for later sessions)

### ⚠️ Privacy Note

Free AI APIs (Google, OpenAI, etc.) may use your data to improve models. **Only use public, synthetic, or anonymized data in this course.** Never send confidential or client data.
